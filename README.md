# By the Numbers Bookkeeping Service Website

Static website for By the Numbers Bookkeeping Service.

## Files

- `index.html` — homepage
- `styles.css` — site design
- `script.js` — mobile menu and current year
- `assets/` — portrait and favicon

## Cloudflare Pages Settings

This is a static site. If Cloudflare asks for build settings:

- Framework preset: None
- Build command: leave blank
- Build output directory: `/`

## Deployment

Upload these files to the GitHub repository root. Cloudflare Pages will redeploy automatically.
